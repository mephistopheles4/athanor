# Specs

This folder holds the repo's specs in force, one file each: `<NNNN>-<slug>.md`. `NNNN` is four digits, the highest in the folder plus one, from `0001`; `slug` is lower-case letters, digits and hyphens. Whether a spec is in force is decided by the owner's rule, `~/.claude/tracker.md` ("Specs in the tree"), not by this file. Every file here is public, so a spec holds nothing a public record may not: no secret, personal detail, open security reason, weakness in others' software that is not yet public, or Linear id beyond a team key.

To add a spec: write the file, put its line at the top of "All specs" (and delete `None yet.` there if it is the first), and change nothing else. A line is one of:

- `- [<stem>](<stem>.md) — <one-line summary>`, `<stem>` being the file name without `.md`;
- `- history: [#<n>](<issue URL>) — <one-line summary>`, for a spec still on an issue; it names no file.
